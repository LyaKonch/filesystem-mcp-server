# Automation Scripts

This directory contains operational scripts for both Linux (`.sh`) and Windows (`.bat`).


## Development
- `dev_start.sh`
- `dev_start.bat`

## Production start
- `prod_start.sh`
- `prod_start.bat`

## Deployment and update
- `deploy.sh`, `deploy.bat`
- `update.sh`, `update.bat`

## Backup and restore
- `backup.sh`, `backup.bat`
- `restore.sh`, `restore.bat`
