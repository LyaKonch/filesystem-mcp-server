Usage¶

Build documentation¶

From the project root on Windows:

.\make.bat html

Useful targets:

  • .\make.bat help — list available builders.

  • .\make.bat clean — remove build artifacts.

Output path¶

Generated HTML is available in build\html\index.html (or _build\html depending on your quickstart layout).

mcp-server
